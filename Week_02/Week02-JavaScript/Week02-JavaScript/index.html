Week 02 tasks

Three pages, each one built with an external stylesheet and an external JavaScript file. Nothing is calculated on the server — every total is produced by JavaScript running in the browser.

Task 1 — Bill splitter

Enter the total bill, choose a tip rate (0%, 5%, 10%, 15% or 20%) and the number of people. The page shows the bill with the tip added and what each person should pay. Inputs are validated; invalid values are highlighted and the user is told exactly which items are wrong.

Task 2 — Menu bill

The total bill input has been removed. Instead the user adds each menu item and its cost, and the total bill is derived from the list when the split button is pressed.

Task 3 — To-do list

Add tasks and tick them off as they are completed. Completed tasks are struck through and a counter tracks progress. The list is held in memory only, so refreshing the page clears it, as required.
